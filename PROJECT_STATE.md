# PROJECT STATE — Godot Character 3D

## Project
- Repository: `mcsmokco/Godot-character-3D`
- Engine: Godot 4.x
- Development target: Mobile-first workflow (Android)
- Purpose: Create and program a reusable 3D character entirely from a phone.

## Scope
This repository is completely independent from the Digital Marketing Pro project.

### Planned pipeline
1. Create/design the 3D character on mobile.
2. Prepare topology, materials and textures.
3. Rig the character with a skeleton.
4. Add/import animations: Idle, Walk, Run, Jump.
5. Import the character into Godot 4 as GLB/GLTF.
6. Build a CharacterBody3D controller.
7. Add gravity, movement, rotation and jumping.
8. Add third-person camera.
9. Add mobile touch controls / virtual joystick.
10. Optimize the character and project for mobile performance.
